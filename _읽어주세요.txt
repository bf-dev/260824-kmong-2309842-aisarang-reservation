아이사랑 시간제보육 예약 프로그램
=================================

1. 준비
   - 아이사랑(www.childcare.go.kr) 에 공동인증서가 등록되어 있어야 합니다.
   - 중요: 시간제보육 신청 화면은 공동인증서(또는 간편인증) 로그인에서만 열립니다.
     아이디/비밀번호로 로그인하면 화면이 비어서 나옵니다. 사이트가 그렇게 막아둔 것이라
     프로그램이 우회할 수 있는 부분이 아닙니다. (2026-08-24 실제 확인)
   - 아이사랑에 아동등록(시간제보육 아동등록)이 미리 되어 있어야 합니다.
   - 크롬(Chrome)이 설치되어 있어야 합니다.

2. 설치 (압축 풀기) 와 실행
   내려받으신 파일은 ZIP 압축파일입니다. 순서대로만 해주세요.

   1) 내려받은 aisarang-reservation-1.0.5.zip 을 마우스 오른쪽 클릭 → [속성]
      → 아래쪽에 "보안: 이 파일은 다른 컴퓨터에서 전송되었으며..." 와 함께
      [차단 해제] 체크칸이 보이면 체크하고 [확인] 을 누르세요.
      (체크칸이 안 보이면 그냥 넘어가시면 됩니다.)
   2) 다시 오른쪽 클릭 → [압축 풀기] 로 압축을 풉니다.
      바탕화면처럼 찾기 쉬운 곳에 푸세요.
   3) 풀린 폴더 안의 aisarang-reservation.exe 를 더블클릭하면 창이 뜹니다.

   - exe 만 따로 다른 곳으로 옮기면 실행되지 않습니다. _internal 폴더가 항상
     exe 와 같은 자리에 있어야 합니다. 옮기실 때는 폴더 통째로 옮겨주세요.
   - 설정 파일을 손으로 고칠 필요는 없습니다. 전부 화면에서 바꿉니다.
   - 앞서 받으셨던 한 파일짜리 exe (1.0.4) 는 지우셔도 됩니다. 그 형식은 실행할
     때마다 자기 자신을 임시폴더에 풀어놓는데, 윈도우 디펜더가 그 동작을 오탐해
     파일을 막아버립니다("지정한 장치, 경로 또는 파일에 액세스할 수 없습니다").
     이번 폴더 형식은 푸는 동작이 없어서 그 경로를 지나가지 않습니다.
     백신을 끄실 필요는 전혀 없습니다.

3. 화면 순서
   1) 로그인 방식
      - "크롬에서 직접 로그인" : 프로그램이 크롬 창을 띄워줍니다.
        평소처럼 공동인증서로 로그인만 해두시면 됩니다. 나머지는 프로그램이 합니다.
      - "공동인증서 자동 로그인" : 인증서 비밀번호를 이 화면에 넣어두면
        인증서 창이 뜰 때 프로그램이 대신 입력합니다.
        (인증서와 비밀번호는 이 PC 밖으로 나가지 않습니다.)
   2) 지역과 센터
      - 기본값은 서초구육아종합지원센터(신반포) 입니다. 바꾸실 수 있습니다.
      - 다른 곳을 쓰시려면 시/도, 시/군/구를 고르고 [센터 불러오기] 를 누르세요.
   3) 예약 조건
      - 이용일 : "2주 뒤 자동" 이면 그날 오전 9시에 열리는 날짜를
        서버 시각 기준으로 자동 계산합니다.
      - 아동 이름 / 반명 : 비워두시면 화면에 나오는 첫 번째 아동과 반을 씁니다.
        아동이 둘 이상이면 이름을 적어주세요.
      - 이용시간 : 사이트의 "이용시간" 선택칸과 같은 값입니다 (9 = 09:00~18:00).
      - 시작 시간대 : 고르신 순서가 우선순위입니다. 첫 번째가 정원초과면
        다음 것으로 한 번 더 갑니다. 아무것도 안 고르시면 그 날 열려 있는
        첫 칸으로 갑니다.
      - 기본값은 "실제 예약" 입니다. 그대로 두시면 진짜로 예약합니다.
      - 처음 한 번은 "연습" 으로 바꿔서 돌려보시길 권합니다.
        연습은 예약 확인창까지만 열고 [확인] 을 누르지 않으므로,
        예약이 만들어지지 않은 채로 동작만 확인하실 수 있습니다.
   4) [예약 시작] 을 누르고 그대로 두세요.

4. 9시 정각에 하는 일 (중요)
   - 이용일 자체는 자정에 목록에 뜨지만, 실제로 예약이 되는 것은 9시 정각입니다.
   - 그래서 프로그램은 9시가 되기 전에
       검색 → 센터 → 아동 → 반/이용시간 → 날짜 칸 → [추가] → 체크 → [예약하기]
     까지 미리 끝내두고, "예약" 확인창을 열어둔 채 기다립니다.
   - 정각에 누르는 것은 확인창의 [확인] 하나뿐입니다.
     손으로 하실 때 하시던 것과 같은 방식입니다.
   - PC 시계가 아니라 아이사랑 서버 시각에 맞추고, [확인] 요청이 "서버에 닿는
     시각"을 9시에 맞춥니다. 회선 지연만큼 미리 보냅니다.
   - 조금 일러서 사이트가 "예약시간전" 이라고 답하면 자리는 그대로 남아 있으므로
     곧바로 다시 누릅니다. 이때 알아낸 오차로 남은 발사 시각도 바로잡습니다.
   - 조금 늦어서 "정원초과" 가 나오면 그 자리는 이미 나간 것이라 더 누르지 않고,
     그때 화면이 뭐라고 했는지 그대로 알려드립니다.
   - X 나 0 으로 표시된 칸(이용불가 / 남은 자리 없음)은 누르지 않고 보고만 합니다.
   - 날짜 칸이 실제로 선택되지 않았거나 선택표의 체크가 켜져 있지 않으면
     [예약하기] 도 [확인] 도 누르지 않습니다. 엉뚱한 예약이 생기지 않게
     일부러 그렇게 막아두었습니다.

5. 참고
   - 로그인 세션은 60분이면 끊깁니다. 프로그램이 대기하는 동안 10분마다 세션을
     살려두긴 하지만, 확실하게 하시려면 8시 30분 ~ 8시 50분 사이에 켜고
     인증서 로그인을 해두시는 것을 권합니다.
     (준비는 기본으로 9시 4분 전에 시작합니다.)
   - 창을 닫으면 예약도 멈춥니다. 9시가 지날 때까지 켜두세요.
   - 프로그램은 새 버전이 나오면 자동으로 받아 갱신합니다.

문의는 크몽 메시지로 주세요.
