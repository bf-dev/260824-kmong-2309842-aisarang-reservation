아이사랑 시간제보육 예약 프로그램
=================================

1. 준비
   - 아이사랑(www.childcare.go.kr) 에 공동인증서가 등록되어 있어야 합니다.
   - 중요: 시간제보육 신청 화면은 공동인증서(또는 간편인증) 로그인에서만 열립니다.
     아이디/비밀번호로 로그인하면 화면이 비어서 나옵니다. 사이트가 그렇게 막아둔 것이라
     프로그램이 우회할 수 있는 부분이 아닙니다. (2026-08-24 실제 확인)
   - 아이사랑에 아동등록(시간제보육 아동등록)이 미리 되어 있어야 합니다.
   - 크롬(Chrome)이 설치되어 있어야 합니다.

2. 설치 (압축 풀기) 와 실행
   내려받으신 파일은 ZIP 압축파일입니다. 순서대로만 해주세요.

   1) 내려받은 aisarang-reservation-1.0.8.zip 을 마우스 오른쪽 클릭 → [속성]
      → 아래쪽에 "보안: 이 파일은 다른 컴퓨터에서 전송되었으며..." 와 함께
      [차단 해제] 체크칸이 보이면 체크하고 [확인] 을 누르세요.
      (체크칸이 안 보이면 그냥 넘어가시면 됩니다.)
   2) 다시 오른쪽 클릭 → [압축 풀기] 로 압축을 풉니다.
      바탕화면처럼 찾기 쉬운 곳에 푸세요.
   3) 풀린 폴더 안의 aisarang-reservation.exe 를 더블클릭하면 창이 뜹니다.

   - exe 만 따로 다른 곳으로 옮기면 실행되지 않습니다. _internal 폴더가 항상
     exe 와 같은 자리에 있어야 합니다. 옮기실 때는 폴더 통째로 옮겨주세요.
   - 설정 파일을 손으로 고칠 필요는 없습니다. 전부 화면에서 바꿉니다.
   - 앞서 받으셨던 한 파일짜리 exe (1.0.4) 는 지우셔도 됩니다. 그 형식은 실행할
     때마다 자기 자신을 임시폴더에 풀어놓는데, 윈도우 디펜더가 그 동작을 오탐해
     파일을 막아버립니다("지정한 장치, 경로 또는 파일에 액세스할 수 없습니다").
     이번 폴더 형식은 푸는 동작이 없어서 그 경로를 지나가지 않습니다.
     백신을 끄실 필요는 전혀 없습니다.

3. 화면 순서
   1) 실행 방식  ★ 2026-08-26 에 새로 생겼습니다. 기본은 [인계 모드] 입니다.

      [인계 모드] - 제가 확인창까지 만들어 둡니다   (권장, 기본값)
        크롬 창에서 아동 선택 → 반/이용시간 → 날짜 칸 → [추가] → 선택표 체크 →
        [예약하기] 까지 평소 하시던 대로 직접 해주세요.
        "예약하시겠습니까?" 확인창을 띄워만 두시면 됩니다.
        프로그램은 그 확인창의 [확인] 만 9시 정각에 맞춰 누릅니다.
        화면을 옮기거나, 검색을 다시 하거나, 아동을 다시 고르는 일은
        **절대 하지 않습니다.**

        왜 이렇게 바뀌었나 (2026-08-26 기록)
          9시 직전에 [예약하기] 를 누르면 사이트가 대기줄에 세웁니다.
          그날 아침에는 앞에 72명이 서 있었고 예상 대기가 2분 10초였습니다.
          예전 판은 확인창이 8초 안에 안 열리면 실패로 보고 처음부터 다시
          진행했는데, 다시 누를 때마다 대기줄 맨 뒤로 밀려서
          앞에 선 사람이 72명 → 138명 → 177명 으로 늘어났습니다.
          이제는 대기줄을 만나면 그대로 기다립니다.

      [자동 모드] - 프로그램이 처음부터 진행         (예전 방식)
        예전처럼 검색부터 [예약하기] 까지 프로그램이 스스로 합니다.
        대기줄을 만나면 기다리고, 처음부터 다시 하지 않습니다.

   2) 로그인 방식
      - "크롬에서 직접 로그인" : 프로그램이 크롬 창을 띄워줍니다.
        평소처럼 공동인증서로 로그인만 해두시면 됩니다. 나머지는 프로그램이 합니다.
      - "공동인증서 자동 로그인" : 인증서 비밀번호를 이 화면에 넣어두면
        인증서 창이 뜰 때 프로그램이 대신 입력합니다.
        (인증서와 비밀번호는 이 PC 밖으로 나가지 않습니다.)
   3) 지역과 센터
      - 기본값은 서초구육아종합지원센터(신반포) 입니다. 바꾸실 수 있습니다.
      - 다른 곳을 쓰시려면 시/도, 시/군/구를 고르고 [센터 불러오기] 를 누르세요.
   4) 예약 조건  (자동 모드에서 쓰이는 값입니다)
      - 이용일 : "2주 뒤 자동" 이면 그날 오전 9시에 열리는 날짜를
        서버 시각 기준으로 자동 계산합니다.
      - 아동 이름 / 반명 : 비워두시면 화면에 나오는 첫 번째 아동과 반을 씁니다.
        아동이 둘 이상이면 이름을 적어주세요.
        적어주신 이름이 사이트의 아동 목록에 없으면, 다른 아이로 예약하지 않고
        그 자리에서 멈추고 알려드립니다(화면에 있는 아동 목록도 같이 보여드립니다).
      - 이용시간 : 사이트의 "이용시간" 선택칸과 같은 값입니다 (9 = 09:00~18:00).
      - 시작 시간대 : 고르신 순서가 우선순위입니다. 첫 번째가 정원초과면
        다음 것으로 한 번 더 갑니다. 아무것도 안 고르시면 그 날 열려 있는
        첫 칸으로 갑니다.
      - 기본값은 "실제 예약" 입니다. 그대로 두시면 진짜로 예약합니다.
      - 처음 한 번은 "연습" 으로 바꿔서 돌려보시길 권합니다.
        연습은 예약 확인창까지만 열고 [확인] 을 누르지 않으므로,
        예약이 만들어지지 않은 채로 동작만 확인하실 수 있습니다.
   5) 인계 모드면 [[확인] 대기 시작], 자동 모드면 [예약 시작] 을 누르고
      그대로 두세요.

4. 9시 정각에 하는 일 (중요)
   - 이용일 자체는 자정에 목록에 뜨지만, 실제로 예약이 되는 것은 9시 정각입니다.
   - 어느 방식이든 정각에 누르는 것은 확인창의 [확인] 하나뿐입니다.
     손으로 하실 때 하시던 것과 같은 방식입니다.
   - 인계 모드에서는 확인창을 만드는 일까지 직접 하시고, 프로그램은 화면을
     0.5초마다 다시 읽으면서 기다립니다. [예약하기] 를 누르시는 순간
     화면 아래 표시가 "확인창 감지됨" 으로 바뀝니다.
   - 자동 모드에서는 프로그램이 9시가 되기 전에
       검색 → 센터 → 아동 → 반/이용시간 → 날짜 칸 → [추가] → 체크 → [예약하기]
     까지 미리 끝내두고, "예약" 확인창을 열어둔 채 기다립니다.

   화면 아래 표시줄 보는 법 (사진으로 찍어 보내주시면 도움이 됩니다)
     인계 모드 ([확인] 만 누름) | 확인창 감지됨 | 선택표 체크 켜짐 | [확인] 까지 03:12
       → 이 상태면 정각에 누릅니다. 그대로 두시면 됩니다.
     ... | 확인창 없음 | ...
       → 아직 [예약하기] 를 누르지 않으셨습니다. 크롬 창에서 진행해 주세요.
     ... | 가상대기열 대기 중 | ...
       → 대기줄에 서 있습니다. 새로고침하거나 다시 누르지 마세요.
          다시 누르면 맨 뒤로 갑니다. 순번이 오면 확인창이 저절로 열립니다.
     ... | 선택표 체크 꺼짐 | ...
       → 선택표(아래 표) 왼쪽 체크칸을 켜주세요. 꺼져 있으면 누르지 않습니다.
   - PC 시계가 아니라 아이사랑 서버 시각에 맞추고, [확인] 요청이 "서버에 닿는
     시각"을 9시에 맞춥니다. 회선 지연만큼 미리 보냅니다.
   - 서버 시각은 한 번만 맞추고 마는 것이 아니라, 프로그램이 켜져 있는 동안
     5분마다 다시 맞춥니다(전날 오후에 켜두셔도 정각에는 방금 잰 값으로 쏩니다).
     다시 맞출 때마다 화면 아래 기록에 "서버 시각 재측정 ..." 한 줄이 남습니다.
     9시 90초 전부터는 발사에 방해가 되지 않도록 다시 맞추는 일을 멈춥니다.
     다시 맞추기가 실패해도 마지막으로 성공한 값으로 그대로 진행합니다.
   - 조금 일러서 사이트가 "예약시간전" 이라고 답하면 자리는 그대로 남아 있으므로
     곧바로 다시 누릅니다. 이때 알아낸 오차로 남은 발사 시각도 바로잡습니다.
   - 조금 늦어서 "정원초과" 가 나오면 그 자리는 이미 나간 것이라 더 누르지 않고,
     그때 화면이 뭐라고 했는지 그대로 알려드립니다.
   - X 나 0 으로 표시된 칸(이용불가 / 남은 자리 없음)은 누르지 않고 보고만 합니다.
   - 발사 직전에 화면을 다시 읽어서, (1) 예약 확인창이 실제로 떠 있고
     (2) 그 안의 [확인] 버튼이 보이고 (3) 확인창 본문이 예약 확인 문구이고
     (4) 선택표 체크가 지금도 켜져 있는지를 모두 확인합니다.
     하나라도 아니면 [확인] 을 누르지 않고 화면에 이유를 적습니다.
     취소가 센터 전화로만 되기 때문에, 잘못 누르는 것보다 안 누르는 쪽으로
     일부러 막아두었습니다.

5. 진단 기록 (예약이 잘 안 될 때만 쓰시면 됩니다)
   화면 아래쪽 "6. 진단 기록" 칸에 [진단 기록 시작] 버튼이 있습니다.
   저희가 예약 화면의 뒷부분(반/이용시간 → 날짜표 → 추가 → 예약하기 → 확인창)을
   실제로 본 적이 없어서, 그 화면을 그대로 받아 적으려고 만든 기능입니다.

   하시는 순서
   1) [진단 기록 시작] 을 누르시면 크롬 창이 열립니다.
   2) 평소처럼 공동인증서로 로그인하세요.
   3) 그 다음부터 평소 손으로 하시던 대로 진행해 주세요.
      센터 검색 → 아동 선택 → 반/이용시간 → 날짜 칸 → [추가] → 체크 →
      [예약하기] 까지 눌러서 "예약하시겠습니까?" 확인창이 뜨는 곳까지만 가시면 됩니다.
   4) 확인창이 보이면 [확인] 은 누르지 마시고, 프로그램 화면으로 돌아와
      [기록 중지] 를 눌러주세요. 그때 기록이 저희에게 전송됩니다.

   꼭 알아두실 것
   - 이 기능은 예약을 하지 않습니다. 프로그램이 대신 눌러주는 것이 하나도
     없습니다. 화면과 통신 내용을 보고 받아 적기만 합니다.
     그래서 이 모드로는 예약이 만들어질 수 없습니다.
   - 중간에 뒤로 가시거나, 창을 닫으시거나, 빠르게 여러 번 누르셔도 괜찮습니다.
     오류창이 뜨지 않고 그때까지 모은 것은 그대로 전송됩니다.
   - 5분마다 한 번씩 중간 저장도 보내드리므로, PC 가 갑자기 꺼져도 그때까지의
     기록은 남습니다.
   - 아동 이름 같은 개인정보와 로그인 정보(쿠키 값, 비밀번호)는 보내기 전에
     지웁니다. 인증서 비밀번호는 어떤 경우에도 담기지 않습니다.

6. 참고
   - 로그인 세션은 60분이면 끊깁니다. 프로그램이 대기하는 동안 5분마다 세션을
     살려두긴 하지만, 확실하게 하시려면 8시 30분 ~ 8시 50분 사이에 켜고
     인증서 로그인을 해두시는 것을 권합니다.
     (자동 모드의 준비는 기본으로 9시 4분 전에 시작합니다.)
   - 인계 모드 권장 순서
     8시 40분쯤  프로그램을 켜고 [[확인] 대기 시작] 을 누릅니다.
                 크롬 창이 열리면 공동인증서로 로그인하세요.
     8시 50분쯤  크롬 창에서 아동 → 반/이용시간 → 날짜 칸 → [추가] →
                 선택표 체크 → [예약하기] 까지 진행해 확인창을 띄웁니다.
     그 뒤        프로그램 화면 아래가 "확인창 감지됨" 인지 확인하고 그대로 두세요.
                 대기줄이 뜨면 그것도 그대로 두시면 됩니다.
   - 창을 닫으면 예약도 멈춥니다. 9시가 지날 때까지 켜두세요.
   - 프로그램은 새 버전이 나오면 자동으로 받아 갱신합니다.

문의는 크몽 메시지로 주세요.
